About SMARTSCHED

Understanding the problem, architecture and decision logic.

PROJECT OVERVIEW

CPU scheduling, visualized.

SMARTSCHED is a simulation framework combining Operating Systems and Data Structures concepts to compare common CPU scheduling algorithms and automatically select the one with the lowest average waiting time.

PROBLEM STATEMENT

Why scheduling matters

A CPU executes one process at a time, so a scheduler must decide which process receives the CPU next. Different algorithms can produce different waiting-time results for the same workload.

SMART DECISION

Recommendation logic

  1. Collect waiting times.
  2. Compare scheduler results.
  3. Find the minimum.
  4. Declare the corresponding algorithm selected.
