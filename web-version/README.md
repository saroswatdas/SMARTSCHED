# SMARTSCHED Web
Interactive web version of the SMARTSCHED CPU scheduling project.

Features:
- FCFS, SJF, Round Robin and Priority Scheduling
- Add/edit/remove processes
- Configurable Round Robin quantum
- Average waiting-time comparison
- Automatic best-algorithm selection
- Chart.js results chart
- Gantt chart

Open `index.html` in a browser. No backend is required.
