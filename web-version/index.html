SJF

03 PREEMPTIVE

Round Robin

Quantum → Configurable

About SMARTSCHED

SMARTSCHED is a CPU scheduling simulation project combining Operating Systems concepts with Data Structures.

The simulator executes common scheduling algorithms, measures average waiting time, visualizes CPU execution, and identifies the algorithm producing the lowest waiting time.
