Scheduling Algorithms

Definitions, working principles and DSA concepts behind SMARTSCHED.

01 · FIFO QUEUE

FCFS

First Come, First Serve

Processes execute in the order in which they arrive.

DATA STRUCTUREFIFO QueueHOW IT WORKS
  1. Process enters the ready queue.
  2. First process is selected.
  3. It runs until completion.
  4. Next process is selected.
Simple to implement, but long jobs can delay shorter jobs.
02 · SHORTEST JOB

SJF

Shortest Job First

Selects the available process with the smallest CPU burst.

SELECTION RULESmallest Burst TimeHOW IT WORKS
  1. Examine available processes.
  2. Find the shortest burst.
  3. Execute it.
  4. Repeat.
Often gives low average waiting time, but long jobs can starve.
03 · CIRCULAR QUEUE

Round Robin

Time-Quantum Scheduling

Each process receives a fixed amount of CPU time.

DATA STRUCTURECircular Queue
P1 → P2 → P3 → P4 ↻
KEY IDEA

A process that is not finished returns to the back of the queue.

Fair and responsive; performance depends on quantum size.
04 · PRIORITY QUEUE

Priority

Priority Scheduling

Processes are selected according to their priority values.

DATA STRUCTUREPriority Queue
P2 — Priority 1
P3 — Priority 2
P1 — Priority 3
P4 — Priority 4
KEY IDEA

This implementation treats lower numeric values as higher priority.
